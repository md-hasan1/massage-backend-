firebase-service-account.json SETUP INSTRUCTIONS

To allow the backend to send actual push notifications to your Android emulators when the app is closed:

1. Go to your Firebase Console: https://console.firebase.google.com/
2. Open your project settings.
3. Select the "Service Accounts" tab.
4. Click the "Generate New Private Key" button.
5. Save the downloaded JSON file in this directory.
6. Rename the file to:
   firebase-service-account.json

Once you save the file here, restart the backend server. The backend will automatically transition from "Mock mode" to "Live mode" and start sending system push notifications!
